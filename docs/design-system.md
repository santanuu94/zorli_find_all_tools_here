# Zorli Design System & UI Principles

## 1. Brand Identity
- **Name**: Zorli
- **Tagline**: Simple tools for a smarter you.
- **Brand Colors**:
  - Primary Indigo Accent: `#6657FF` (`bg-[#6657FF]`, `text-[#6657FF]`)
  - Violet Accent: `#8B5CF6`
  - Deep Navy Background (Dark Mode): `#070B24`
  - Dark Card / Surface: `#0D1438`
  - Subtle Card Border: `border-white/10` or `border-slate-200/80`
  - Clean Light Surface (Light Mode): `#F7F8FC`

## 2. Typography
- **Headings & Logo**: `Plus Jakarta Sans`, sans-serif (`font-display font-black`)
- **Body & Controls**: `Inter`, sans-serif (`font-sans`)
- **Handwritten Accents**: `Caveat`, cursive (`font-hand text-[#35D9E8]`)
- **Code & Numbers**: JetBrains Mono / monospace (`font-mono`)

## 3. Dark Mode & Accessibility
- Dark mode is enabled by default with support for user toggling via the navigation header.
- Persistent contrast ratios meeting WCAG 2.1 AA standards.
- Distinct focus states and accessible button press targets (minimum 44px on mobile).

## 4. Responsive Viewport Standards
- Fluid layout adapting seamlessly across mobile (320px+), tablet (768px+), desktop (1024px+), and ultrawide monitors (1440px+).
- Sticky navigation header with mobile backdrop blur and collapsible menu.
